# Waybit Digital Evolution

SPEC Conceitual — Website Waybit — Etapa 01

Especificação conceitual da primeira etapa da nova presença digital da Waybit. Esta etapa contempla exclusivamente a construção da Home desde o Header até a seção de Cases/Depoimentos, utilizando a Home atual da Waybit como principal referência de conteúdo, estrutura e linguagem visual.

1. Contexto

A Waybit possui atualmente uma presença digital voltada à apresentação de seus sistemas de gestão empresarial e à geração de contatos comerciais.

A Home atual apresenta a empresa, seus segmentos, soluções, diferenciais e provas sociais, utilizando uma linguagem visual própria e já estabelecida.

Esta primeira etapa do novo projeto tem como objetivo construir somente a primeira parte da Home, começando pelo Header e avançando até a seção de Cases/Depoimentos.

A Home atual será utilizada como:

Referência de conteúdo;

Referência de estrutura;

Referência de identidade visual;

Referência de composição;

Referência de linguagem;

Referência para imagens;

Referência para componentes;

Referência para espaçamentos;

Referência para comportamento visual.

O objetivo não é criar uma nova identidade visual para a Waybit.

O objetivo é evoluir a experiência e a estrutura mantendo o reconhecimento visual da marca.

A implementação posterior das demais seções deverá continuar a partir da mesma fundação criada nesta primeira etapa.

2. Problema

SintomaConsequênciaA Home possui muitas informações e diferentes caminhos de navegação.O visitante pode ter dificuldade para compreender rapidamente a proposta da Waybit.Diferentes segmentos possuem necessidades diferentes.Uma comunicação genérica pode reduzir a relevância da mensagem.Existem diversas soluções e produtos.O visitante pode não identificar imediatamente qual solução corresponde ao seu negócio.A proposta de valor está distribuída pela Home.O visitante pode precisar percorrer várias áreas para compreender o valor da empresa.A prova social aparece posteriormente na jornada.O visitante pode não receber confiança suficiente durante o processo de decisão.O design atual possui diversos elementos visuais próprios.Uma reconstrução genérica poderia descaracterizar a identidade da Waybit.

14. Direção de Design e Experiência

14.1 Princípio fundamental

A Home atual da Waybit é a principal fonte de verdade visual deste projeto.

O Lovable não deve criar uma nova identidade visual.

O resultado deve parecer uma evolução da Home existente.

A referência visual deve determinar:

Cores;

Tipografia;

Composição;

Espaçamentos;

Cards;

Botões;

Imagens;

Gradientes;

Sombras;

Bordas;

Arredondamentos;

Ícones;

Hierarquia;

Estilo geral.

A criatividade do sistema deve ser utilizada para organizar e implementar, não para substituir a identidade visual existente.

14.2 Referência principal

Website de referência:

https://waybit.com.br

O site deve ser analisado como referência geral.

As imagens fornecidas posteriormente terão função de complementar a análise visual.

Quando houver conflito entre uma decisão genérica do sistema e uma referência fornecida, a referência deve prevalecer.

14.3 Tipografia

Utilizar exclusivamente:

Rubik

Pode ser utilizada para elementos que, na referência atual, apresentem essa característica.

Poppins

Pode ser utilizada para elementos que, na referência atual, apresentem essa característica.

Não utilizar:

Inter;

Roboto;

Arial;

Montserrat;

Open Sans;

ou qualquer outra família.

A combinação Rubik + Poppins deve permanecer como base tipográfica do projeto.

14.4 Cores

Preservar as cores observadas na Home atual.

Não criar nova paleta.

As cores devem manter suas funções atuais:

Fundo;

Texto;

Títulos;

Destaques;

Botões;

Links;

Cards;

Elementos gráficos.

Gradientes existentes devem ser preservados.

14.5 Containers e grid

Manter a sensação de organização visual existente.

Os conteúdos devem apresentar:

Alinhamento consistente;

Largura controlada;

Respiro lateral;

Relação entre seções;

Espaçamento vertical coerente.

Evitar conteúdos encostados nas bordas da tela.

14.6 Cards

Cards devem seguir o padrão visual da Home atual.

Preservar, conforme referência:

Raio;

Bordas;

Sombras;

Fundo;

Espaçamento;

Hierarquia;

Ícones;

Imagens.

Não utilizar estilos diferentes para cards que possuem a mesma função.

14.7 Botões

Os botões devem preservar a aparência dos CTAs atuais.

Considerar:

Forma;

Arredondamento;

Tipografia;

Peso;

Espaçamento;

Ícone;

Hover;

Contraste.

O botão principal deve possuir destaque superior aos links secundários.

14.8 Imagens

As imagens fornecidas pelo responsável pelo projeto devem ser utilizadas fielmente.

Não substituir imagens oficiais por imagens genéricas.

Preservar:

Proporção;

Enquadramento;

Transparência;

Qualidade;

Tratamento;

Posicionamento.

14.9 Logos

Todas as logos fornecidas podem ser utilizadas fielmente.

Não:

redesenhar;

modificar;

distorcer;

trocar cores;

substituir por texto;

substituir por ícones genéricos.

A logo fornecida é a fonte de verdade daquele elemento.
